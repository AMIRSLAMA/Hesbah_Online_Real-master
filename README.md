# Hesbah POS v1.3.0

نسخة Hesbah مبنية على مشروع AmirCasher السابق، مع الحفاظ على نظام التفعيل الداخلي.

## الدخول
- المستخدم: `admin`
- كلمة المرور: `admin`

## الإضافة الجديدة
- صفحة **قائمة الأسعار QR**.
- QR واحد شامل جميع الأصناف والأسعار.
- يظهر اسم المحل ولوجو المحل في ورقة الطباعة.
- يمكن تحديث القائمة بعد تعديل المنتجات والأسعار.
- يمكن طباعة QR وقائمة الأسعار من داخل البرنامج.

## مهم
- توليد صورة QR يتم عبر QuickChart، لذلك يلزم اتصال بالإنترنت وقت توليد/طباعة QR.
- باقي بيانات البرنامج محفوظة محليًا.

## التشغيل
```bash
npm install
npm start
```

## بناء ملف التسطيب
```bash
npm run dist
```
أو شغّل `build-installer.bat`.

## التفعيل
صفحة الإعدادات > التفعيل تعرض حالة التجربة وMachine ID. التفعيل ما زال مرتبطًا بالجهاز.
