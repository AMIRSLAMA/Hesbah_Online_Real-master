# Hesbah Mobile

تطبيق Android خفيف يفتح Hesbah Online داخل WebView.

## الاختبار
- شغّل `online` على جهاز التطوير.
- عنوان المحاكي الافتراضي: `http://10.0.2.2:8080`.

## السيرفر الحقيقي
عدّل `HESBAH_URL` داخل `app/build.gradle` إلى عنوان HTTPS الخاص بسيرفر Hesbah، ثم افتح مجلد `mobile` في Android Studio وابنِ APK.
