# Hesbah Online

نسخة أونلاين أولية عملية لنظام حسبة، تعمل من المتصفح وتدعم الهاتف كـ PWA.

## التشغيل
1. ثبّت Node.js 18 أو أحدث.
2. افتح مجلد `online`.
3. شغّل `npm start`.
4. افتح `http://localhost:8080`.
5. الحساب التجريبي: المتجر `demo` — المستخدم `admin` — كلمة المرور `admin`.

## النشر
يمكن تشغيل المجلد على VPS أو خادم Windows/Linux. اضبط `HESBAH_SECRET` قبل النشر.
البيانات تحفظ في `online/data`، ويمكن لاحقًا استبدال طبقة التخزين بقاعدة PostgreSQL/MySQL دون تغيير واجهة API الأساسية.


## متابعة حالة الطلب والدليفري
- العميل يرى حالة الطلب تلقائياً ويتم تحديثها كل 5 ثوانٍ.
- عند خروج الطلب للتوصيل يمكن للموظف إنشاء رابط خاص بالدليفري.
- يفتح الدليفري الرابط على هاتفه ويضغط «بدء التوصيل وإرسال موقعي».
- العميل يرى موقع الدليفري على الخريطة عند وصول أول إحداثيات GPS.
- تحديد موقع العميل في شاشة الدفع اختياري، ويسمح بعرض موقع العميل والدليفري معاً.
- تحديد الموقع يحتاج HTTPS على الهاتف (أو localhost أثناء الاختبار).
